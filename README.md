# Predicting Temperature Using Weather Data

## Overview
This project builds and compares predictive machine learning models to estimate temperature based on key environmental variables such as humidity, surface pressure, wind speed, and precipitation.

## Datasets Used
1. **Open-Meteo Historical Weather API**: Hourly historical weather data collected for Auckland, New Zealand.
2. **Jena Climate Dataset (Kaggle)**: Benchmark meteorological dataset used for secondary model exploration and comparative analysis.

## Machine Learning Models
* Linear Regression
* Polynomial Regression
* k-Nearest Neighbors (kNN)

## Tech Stack
* Python / Jupyter Notebook
* Pandas & NumPy (Data Processing)
* Scikit-Learn (Model Building & Evaluation)
* Matplotlib & Seaborn (Data Visualization)
